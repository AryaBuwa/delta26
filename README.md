# DEΔTA

AI vs Humans. 104 FIFA World Cup 2026 matches. Who predicts better?

Live prediction system that fetches real-time match data, parses events using LLMs, and updates an XGBoost model after every match. Humans vote on each match. The gap between algorithmic forecasting and human intuition is measured across the entire tournament.

**Status:** Deploying. Live link coming soon.

Built with Python 3.13 · FastAPI · Next.js 15 · Groq · XGBoost · Supabase
